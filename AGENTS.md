# Instrucciones para Codex

Antes de crear specs, editar codigo o responder preguntas de implementacion en este repo:

1. Lee todos los archivos en `SDD/steering/`.
2. Trata esos archivos como la fuente de verdad del proyecto.
3. Si vas a iniciar una spec nueva, crea primero una branch nueva con el formato `codex/spec-<slug-corto>`.
4. Guarda las specs en `SDD/specs/<slug-corto>/`.
5. Cada spec debe tener `requirements.md`, `design.md` y `tasks.md`.
6. Manten las specs pequenas, claras y utiles para demo.
7. Usa espanol para documentacion y copy visible de producto, salvo que la spec indique otra cosa.
8. Cuando empieces trabajo SDD, menciona brevemente que steerings revisaste.

El proyecto de Vercel/v0 publicado en `https://v0-machine-administration-app.vercel.app/` se usa como mockup visual de referencia, no como restriccion tecnica de implementacion.
